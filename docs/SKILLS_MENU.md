# Меню скиллов Made in Heaven (RotP)

В Ripples of the Past **отдельного кастомного меню нет** — стандартный UI стенда:

## Как открывается
- Стенд призван
- Иконки скиллов в **хотбаре способностей**
- Полный список — в Power / Stand inventory

## Раскладка (из JAR Weever)

### ЛКМ
| Скилл | Как |
|-------|-----|
| **Punch** | ЛКМ |
| **Barrage** | ЛКМ (вторая ячейка) |
| **Heavy Punch** | **Shift + Punch** или **Shift + Barrage** |
| **Chop** | Finisher от Heavy Punch |

### ПКМ
| Скилл | Как |
|-------|-----|
| **Block** | ПКМ |
| **Light Speed Dash** | ПКМ / клавиша C |
| **Time System** | ПКМ |
| **Universe Reset** | ПКМ (resolve 4) |

Это уже было в оригинальном `InitStands` (`shiftVariationOf` для heavy).
