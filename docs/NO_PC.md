# Нет ПК / Termux без Java

## Что работает сейчас
Положи в mods **оригинальный** RotP-MadeInHeaven-1.2.5-1.jar
- Все скиллы (панч / бараж / shift heavy / dash / time / reset)
- Меню RotP уже есть

## Почему нельзя «просто сделать jar» здесь
Новый код нужно **скомпилировать** с Java 8 + ForgeGradle + jar RotP.
Без этого получается только патч ресурсов (текстуры), не новая логика.

## Варианты
1. **GitHub Actions** (workflow уже в репо) — сборка на серверах GitHub с Java 8.
   Нужен jar RotP в `libs/` (лучше на **private** fork, чтобы не лить чужой мод в public).
2. Попросить друга с ПК собрать ZIP один раз.
3. Играть на **оригинальном** MiH 1.2.5 — он рабочий.
